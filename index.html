수강신청 선택 그룹 설정

같은 학기 열의 같은 배경색으로 선택 그룹을 구성합니다. 색 없는 과목은 학기별 미분류에서 편집·배치하세요. 선택 수는 직접 지정하며 다른 학기의 그룹으로 이동할 수 없습니다. 이전 그룹 설정은 학기별로 새로 지정해야 합니다. 색상 정보가 없는 기존 편제표는 다시 업로드한 뒤 색상으로 다시 구성하세요.

온라인 신청 결과는 자동으로 집계표에 연동됩니다. 차수를 선택해 해당 결과를 확인하세요.

테스트용 결과 엑셀은 선택한 학년만 저장·교체하며 다른 학년은 유지합니다. 확인서·집계표는 차수별 두 학년 데이터를 함께 사용하며, 차수 데이터 삭제는 두 학년 모두에 적용됩니다.

개발자 전용 · 선택한 학년·차수의 결과 엑셀을 업로드하면 해당 학년만 교체해 확인서·집계표에 반영합니다. 다른 학년은 유지됩니다. 온라인 연동 차수는 먼저 연동을 해제하세요.
