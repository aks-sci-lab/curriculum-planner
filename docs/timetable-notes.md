# 시간표 편성 — 지금까지의 조건·시험 결과 (인계 메모)

조정자 세션이 실제 자료(저장소 밖, 커밋 금지)로 시험한 내용을 숫자만 옮긴 것입니다. 학생·교사 실명은 없습니다.
`docs/timetable-proto/`는 그때 쓴 시제품 스크립트(앱 코드 아님, 참고용)입니다: `build3.cjs`(5·6단계 결과 → 모형 입력·담금질·점검), `build3-check.cjs`(점검), `cpsat.py`(OR-tools CP-SAT 모형), `precheck5*.py`(사전 추정). 입력 JSON은 실제 자료라 없습니다.

## 사용자가 정한 조건 (2026-11-11 ~ 12)
- 학급 수(2027): 1학년 10, 2학년 11(현 1학년 10반 → 11반 재편성), 3학년 11.
- 1학년은 이동수업 없음(반 수업만). 2·3학년 이동수업은 6단계 분반 결과(블록).
- 점심: 3학년은 3교시 뒤, 1·2학년은 4교시 뒤. 절대 시간 축 하루 8칸 `1,2,3,A,B,5,6,7`(A = 3학년 점심·1·2학년 4교시, B = 1·2학년 점심·3학년 4교시).
- 창체: 처음에는 금 6·7 고정이었으나, **시간표 편성을 위해 학년별로 차등 분배해도 무방**(2026-11-12).
- 통합과학 4시간 = 반마다 물리·화학·생명·지구 교사 1시간씩. 통합사회는 교과 분배(5단계 `commonModes` equal/time/class, 반별 배정 `hoursCommonClassAssignment`).
- 3학년 정보·기술 교사 증원 1명.
- 교사 규칙: ① 연강 3시간 이하 ② 점심 앞뒤 한 시간씩 공강(최대한) ③ 같은 날 같은 과목 최소화(교사 기준) ④ 주 2회 이상 수업은 같은 날 2회 금지 ⑤ 담임교사가 그 학년 수업을 하면 담임반 배정(해석 확인 필요, 담임 명단 없음 → 가상 담임).
- 필수: 교사 겹침 금지, 반 겹침 금지, 반 공강 금지(하루 안 빈칸은 뒤쪽만).
- 5단계 확대학급(수준별 이동수업, `settings.expandedClassesOn`·`expandedClasses`)은 시수에만 반영, 6단계·시간표 미반영.
- 사용자 목표(2026-11-12): **조건을 앱에서 고치면서 편성**, **어떤 경우에도 시간표가 나오게**.

## 시험 결과 (CP-SAT 9.15, 실제 자료)
- 3학년 11반이 모두 같은 시간에 택5 블록을 들으면 반 수업 칸이 학년 전체에서 같은 13칸뿐 → 반 수업 교사(체육 3 + 정보 2 + 증원 1)가 동시에 11반을 못 메움 → 교사 겹침.
- 해법: 3학년을 반군으로 나눠 블록 일부(k개)를 반군마다 다른 시간에 둠(분반을 반군별로 다시 나눔 → 분반 수 증가).
  - 반군 2개(1~6 / 7~11반) · k=2: **1학기 필수 위반 0**(분반 88 → 102, 분반 바뀌는 학생 86명). 2학기는 필수 만족 해 없음(증명) — 공강을 소프트로 두면 3학년 5개 반 6곳(10칸) 공강이 최선. 원인: 발명 5반 20시간을 증원 교사 1명이 맡음 + 반군 전체가 동시에 반 수업이어야 메워지는 칸.
  - 반군 3·4·5개(연속 반/형별) × k 2~5: 1·2학기 모두 불가능(사전 추정에서 걸러지거나 CP-SAT 증명). 분반 88 → 108~268, 10명 미만 분반 11~199개, 교사 2명 교과(지리·지구)가 44시간 초과, k≥3이면 사회·과학 교과군 초과. 시수가 맞는 조합도 3학년 공강 금지에서 막힘(교사 상한·점심·연강을 풀어도 불가능, 공강 금지를 풀면 가능).
- 사전 추정(2초): 분반 수 = Σ 올림(반군 학생 ÷ 정원), 블록 안 분반 → 교사 이분 매칭, 교사 후보 묶음별 시수 합 ≤ 22 × 교사 수.
- CP-SAT는 A단계(3학년 반 수업 + 블록 + 분반 교사) → B단계(전체) 두 단계, A 30분 제한.
- 브라우저용 순수 JS 풀이기가 CP-SAT 결과에 얼마나 가까이 가는지는 조정자 쪽에서 시험 중(결과는 따로 전달).
