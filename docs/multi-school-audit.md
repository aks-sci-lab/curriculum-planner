# 다른 학교에서 쓰려면 — 코드에 박힌 '이 학교 고유의 가정' 점검

- 대상: `wt-tt` 작업 트리(브랜치 `claude/timetable-design`, `APP_VERSION 2026.11.25`), 읽기 전용 조사(코드 수정 없음).
- 방법: grep으로 상수·문구·정규식을 찾아 해당 구간만 읽음. 화면을 실제로 띄워 확인하지는 않았음(= 화면 동작은 코드 읽기 기준).
- 분류: **A** 이미 설정으로 바꿀 수 있음(기본값만 이 학교 값) / **B** 코드 상수(설정으로 빼면 됨) / **C** 구조 자체가 이 학교 방식(양식·흐름 일반화 필요).
- 줄 번호는 '근처'입니다. '미확인'은 이번 조사에서 확인하지 못한 것입니다.

## 먼저 고칠 것 10개 (다른 학교가 처음 5분 안에 막히는 순서)

1. **편제표가 안 읽힐 때 이유를 보여 주기** — `layout.planDataError`를 업로드 상태 줄에 내고, 어느 머리글(과목명·학기 열)을 못 찾았는지 알려 주기. 지금은 조용히 예전 표 방식으로 내려감(`curriculum-data.js` 953행, `app.js` 8140~8201행). 작음.
2. **지원하는 편제표 양식 예시 + 빈 양식 내려받기** — 화면에 편제표 예시가 없음(결과 예시만). 중간.
3. **머리글·표기 인식 넓히기 + 열 직접 지정** — '과목명/세부과목'·'기준/운영학점'·`택n`·'학교지정/학생선택'·'교차집중' 낱말을 설정 자료로 빼고, 못 찾으면 사용자가 열을 고르게(`importedPlanColumnMap` 7680행, `planDataTag` 34행, `planDataDivision` 72행). 중간.
4. **시작 안내와 학년도 기본값** — 첫 실행 때 학교명·학년도(오늘 날짜로 제안, 지금은 2026 고정)·'입학생 편제표 3개부터' 순서 안내(`index.html` 800행). 작음.
5. **'울산' 표시 정리** — '교육청 양식으로 내보내기'·울산 불러오기·"울산 지침의 기준값" 문구를 '울산 편제 점검 프로그램용'으로 분명히 하고 교육청 선택(없음/울산)을 설정으로. 작음.
6. **웹 수강신청의 서버를 어떻게 할지 결정** — 지금은 다른 학교 학생 성명이 운영자 Supabase 프로젝트에 저장됨. (가) 공용 서버로 받는다면 개인정보 처리 안내·학교별 삭제·수량 제한·교사 허용 방식이 필요, (나) 학교별 프로젝트라면 `supabase-config.js`를 설정 화면으로. 결정 전에는 다른 학교에 웹 신청을 열지 않는 편이 안전. 중간~큼.
7. **담당 교과 목록을 설정으로** — `HOURS_DEPARTMENTS`에 교과 추가·이름 바꾸기(한문, 제2외국어 언어별, 연극, 전문교과 등), 과목 → 교과 추정 규칙의 '예술 = 음악' 같은 기본값 손보기. 5·6·7단계가 같은 목록을 읽음. 중간.
8. **4단계 'n × 학급 수' 규칙과 개설 기준 식을 선택으로** — 총 학급수 불일치 표시 끄기/허용, 절대 인원 기준 추가(`aggregateThresholds` 4598행, index.html 902~910행). 중간.
9. **기본값이 '이 학교 값'인 곳에 표시 + 학교 설정 묶음 내보내기** — 90/110/34, 19/13, 점심 3학년 3교시, 진로 10시간, 창체 2 등을 한 화면(학교 설정)에서 보고 파일로 넘기기. 중간.
10. **5단계 시수표·4단계 집계표 양식을 '이 학교 양식'으로 이름 붙이고 일반 양식 하나 추가** — 최소한 교과군 묶음·메모 문구를 설정으로, 전년도 시수표 올리기는 같은 양식만 읽는다는 안내. 큼(우선은 안내만 = 작음).

(뒤 순위: 내년 1학년 이동수업·확대학급·격주를 6·7단계에 반영 — 큼, 설계 T7·T8과 함께.)

## 손대지 않아도 되는 것 (이미 일반적인 부분)

- **학교명·확인 날짜**: 설정값, 코드에 학교명 하드코딩 없음.
- **편제표 데이터 편집·띠 표시·변경 이력·엑셀 내보내기**(올린 원본 양식을 그대로 따름), 전학년 자동 생성(Y 양식을 따름).
- **공식 과목명 목록·자동 수정**(2022 개정 833과목, 국가 기준), 위계(선이수) 점검 규칙(경고만, `state.courseChecks`에서 고침).
- **편제 점검 기준값**: 설정 팝업에서 모두 고칠 수 있고 학생 점검과 한 곳을 씀.
- **차수 흐름**(새 차수 = 직전 복사, 확정·스냅샷), 결과 취합의 과목명 정규화·개설 학기 정하기.
- **나이스 '수강학생 편성' 올리기/내보내기의 열 구성**(전국 공통 양식).
- **6단계 분반 계산**(정원·블록 수·방식·교사·불가 시간·특별실 모두 입력값, 학년 고정 분기 없음), 진급 때 반 편성 선택.
- **7단계 시간 구조**(요일·요일별 교시·학년별 점심·창체 방식·규칙 수준)와 구성 휴리스틱(학년 번호가 아니라 '반 수업 교사 < 반 수' 조건).
- **저장소**(IndexedDB 조각 저장·백업 형식 2·PC 파일 저장)와 로컬 전용 원칙 — 웹 신청을 쓰지 않으면 서버 의존 없음.
- **행 보안**: 교사별 분리(`owner_id = auth.uid()`)는 되어 있음(학교별 분리는 아님 — 9번).
