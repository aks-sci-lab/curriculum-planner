수강신청 선택 그룹 설정

같은 학기 열의 같은 배경색으로 선택 그룹을 구성합니다. 색 없는 과목은 학기별 미분류에서 편집·배치하세요. 선택 수는 직접 지정하며 다른 학기의 그룹으로 이동할 수 없습니다. 이전 그룹 설정은 학기별로 새로 지정해야 합니다. 색상 정보가 없는 기존 편제표는 다시 업로드한 뒤 색상으로 다시 구성하세요.

온라인 신청 결과는 집계표의 신청 결과 새로고침 버튼으로 가져옵니다. 차수를 선택해 마지막으로 가져온 결과를 확인하세요.

테스트용 결과 엑셀은 선택한 학년만 저장·교체하고 다른 학년 자료는 유지합니다. 확인서·집계표·이동수업 반편성은 학년 탭별로 분리해 표시합니다. 차수 데이터 삭제는 두 학년 자료 전체에 적용됩니다.

개발자 전용 · 선택한 학년·차수의 결과 엑셀을 업로드하면 해당 학년만 교체해 확인서·집계표에 반영합니다. 다른 학년은 유지됩니다. 온라인 연동 차수는 먼저 연동을 해제하세요.

과목별 수강 신청 집계 1차

학생별 신청 명단에서 과목별 인원을 계산했습니다.

온라인 결과는 자동으로 갱신하지 않습니다. 신청 결과 새로고침을 눌러 최신 결과를 가져오세요.

편제 학급수 입력 후 분반 수 자동 조정을 누르면 현재 학년·차수의 선택군별 학급수를 신청 인원에 비례해 재배분합니다. 조정 후에도 과목별 수동 수정이 가능합니다.

학급당 기준 인원은 학년별 재적 학생 수 ÷ 명단의 반 수로 계산합니다. 편제 학급수는 학년별로 지정할 수 있으며, 각 선택군의 총 학급수는 편제 학급수 × 해당 그룹에서 선택할 과목 수로 계산됩니다. 선택 수는 2단계 그룹 설정을 따릅니다. 신청 인원이 개설 기준보다 적은 과목은 폐강 예정으로 표시됩니다. 과목별 개설 학급수 칸은 직접 수정할 수 있으며 엑셀에 반영됩니다.
